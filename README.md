# シンプルPDF

Windows 64bit用のPDF結合・分解・回転ツールです。既存のpdf_asとは独立した新規アプリです。

## 配布・起動

`dist/SimplePDF.exe` をメンバーへ渡し、ダブルクリックで起動します。
PythonのインストールやDLLの個別配置は不要です。内部のライブラリは起動時に一時フォルダーへ自動展開されます。
ライセンス情報は配布ZIPに同梱しています。

## 操作

画面右上の「？」ボタン、またはF1キーで使い方を表示できます。
Alt+Jで結合、Alt+Sで選択したPDFを分解できます。処理中のキー操作は受け付けません。
結合・分解・回転が正常に完了すると一覧を空にします。失敗した場合は一覧を残します。

1. ファイルを一覧へドロップ、または「ファイル追加」で選びます。
2. 「上に」「下に」で順番を変更します。Ctrl+Aで全選択、Deleteで一覧から除外します。
   追加時は、名前が「システム系統図」「ケーブル系統図」「空中線系統図」で始まるファイルを一覧の末尾へ、この順にまとめます。末尾からは「空中線→ケーブル→システム」です。同種はファイル名の数字順（1、2、10）です。他のファイル同士の順番は変えません。整列後の手動変更も可能です。
3. 「結合して保存」は一覧全体を上から順に1つのPDFにします。画像1枚だけのPDF化もできます。
4. PDFを1つ選択して「1ページずつ分解」で、保存先の新しい専用フォルダーへ各ページを出力します。
5. PDFを1つ選択して回転ボタンを押すと、全ページを回転して別名で保存します。

保存先のダイアログは表示せず、参照PDFと同じフォルダーへ自動保存します。
結合は一覧の最初のPDFを基準に「元の名前_結合.pdf」、回転は「元の名前_回転.pdf」とします。
PDFがない場合は最初の画像を基準にします。同名の出力がある場合は連番を付けます。
分解は対象PDFと同じフォルダー内に専用フォルダーを作成します。

対応入力：PDF、SVG、JPEG、PNG、BMP、TIFF、WebP。出力はPDFです。
一覧の「ページ数」にPDFのページ数を表示します。読み込み中は「確認中」、読み込めないPDFは「読取不可」、画像は「—」と表示します。
同じファイルの重複追加は省略します。元ファイルへの上書き保存はできません。
画像は96dpiでページサイズを決め、縦横比を保ちます。透過部分は白背景になります。
SVGはベクター変換しますが、複雑なフィルター・外部フォント等は完全には再現できない場合があります。
SVGの代表的な日本語フォント指定は、実行PCのMSゴシックで代替します。
パスワード付きPDFは、空パスワードで開けるもの以外は対象外です。
PDFの電子署名の維持やフォーム機能の完全な維持は保証していません。

## 開発

Python 3.12 / Windows 64bitで `./build.ps1 -Python python` を実行します。
処理部分は `engine.py`、画面は `app.py`、検証は `test_app.py` です。
`$env:PYTHONPATH='./vendor'; python -m unittest test_app -v` でテストできます。
